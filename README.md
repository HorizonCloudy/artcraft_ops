# artcraft_ops

N.E.K.O 插件：用一句话操控本机 **ArtCraft 系列软件** —— 检索命令 → 编排序列 → 无头执行 → 回传图片。

- 插件源码与使用说明：[`artcraft_ops/`](artcraft_ops/)（[README](artcraft_ops/README.md)）
- 当前版本：1.0.10（`.neko-plugin` 包由本地构建，不入库）
- 设计规格：[`spec/ARCHITECTURE-FINAL.md`](spec/ARCHITECTURE-FINAL.md)（唯一有效版本）
- 许可：GPL-3.0-only，见 [`LICENSE`](LICENSE)

本项目与 ArtCraft 官方无关，不是官方插件。
